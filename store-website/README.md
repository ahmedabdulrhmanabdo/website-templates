# قالب متجر إلكتروني (7 صفحات)

عربي RTL متجاوب بـ HTML/CSS/JS بدون مكتبات. السلة والمفضلة تُحفظ في `localStorage` وتعمل بين الصفحات.

| الصفحة | المحتوى |
|---|---|
| index.html | سلايدر، التصنيفات، عروض الساعة بعدّاد، الأعلى تقييمًا، آراء، نشرة بريدية |
| shop.html | 16 منتجًا: فلترة (تصنيف/سعر/تقييم/تخفيض/متوفر)، ترتيب، بحث، ترقيم صفحات |
| product.html?id=N | معرض ألوان، مقاسات، كمية، تبويبات (وصف/مواصفات/تقييمات)، منتجات مشابهة |
| cart.html | تعديل الكميات، كود خصم (SAVE10 / FREESHIP)، شريط الشحن المجاني، ضريبة 15% |
| checkout.html | بيانات الشحن، طريقة الشحن والدفع (تجريبي)، رقم الطلب |
| wishlist.html | المفضلة |
| support.html | تتبّع الطلب، أسئلة شائعة، السياسات، نموذج الدعم |

التخصيص: المنتجات في مصفوفة `P` أعلى `script.js`. الدفع وهمي ولا تُحفظ أي بيانات بطاقات.
