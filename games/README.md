# ألعاب بسيطة

سبع ألعاب تعمل مباشرة في المتصفح بدون تثبيت أو مكتبات. افتح `index.html` في هذا المجلد لتصفّحها.

| اللعبة | الوصف |
|---|---|
| tic-tac-toe | إكس أو ضد كمبيوتر يستخدم خوارزمية minimax |
| memory-game | لعبة ذاكرة بـ 8 أزواج وعدّاد حركات |
| snake-game | الثعبان، أسهم أو WASD أو سحب على الجوال، ويحفظ أعلى نتيجة |
| guess-number | خمّن رقمًا من 1 إلى 100 في 7 محاولات |
| rock-paper-scissors | حجر ورقة مقص مع سجل الفوز |
| whack-a-mole | اضرب الخلد خلال 30 ثانية |
| game-2048 | ادمج الأرقام، أسهم أو سحب |
