# ألعاب بسيطة

13 لعبة تعمل مباشرة في المتصفح بدون تثبيت أو مكتبات. افتح `index.html` في هذا المجلد لتصفّحها.

| اللعبة | الوصف |
|---|---|
| tic-tac-toe | إكس أو ضد كمبيوتر يستخدم خوارزمية minimax |
| connect-four | أربعة في صف ضد الكمبيوتر |
| memory-game | لعبة ذاكرة بـ 8 أزواج وعدّاد حركات |
| snake-game | الثعبان، أسهم أو WASD أو سحب، ويحفظ أعلى نتيجة |
| flappy-bird | الطائر، المسافة أو اللمس، ويحفظ أعلى نتيجة |
| game-2048 | ادمج الأرقام، أسهم أو سحب |
| minesweeper | كاسحة الألغام 9×9، نقرة مطولة أو يمين للعلَم |
| simon-game | سيمون: كرّر التسلسل بالألوان والأصوات |
| hangman | تخمين الكلمة بالعربي |
| typing-test | اختبار سرعة الكتابة بالعربي |
| guess-number | خمّن رقمًا من 1 إلى 100 في 7 محاولات |
| rock-paper-scissors | حجر ورقة مقص |
| whack-a-mole | اضرب الخلد خلال 30 ثانية |
