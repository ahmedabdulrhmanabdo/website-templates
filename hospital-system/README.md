# نظام إدارة المستشفى (ويب)

موقع ويب يعمل مباشرة في المتصفح (HTML/CSS/JS)، وتُحفظ بياناته في `localStorage`.

| الصفحة | الوظيفة |
|---|---|
| index.html | تسجيل دخول تجريبي |
| dashboard.html | مؤشرات، مواعيد 7 أيام، إشغال الأقسام، مواعيد اليوم، تنبيهات المخزون |
| patients.html | إضافة وتعديل وحذف وبحث المرضى |
| appointments.html | حجز المواعيد (مع منع تعارض وقت الطبيب) وتغيير الحالة |
| doctors.html | الأطباء حسب التخصص وتفعيل التوفر |
| beds.html | خريطة الأسرّة: تنويم، خروج، تنظيف |
| pharmacy.html | المخزون، تنبيه المنخفض، تعديل الكمية |
| billing.html | فواتير بضريبة 15%، تحصيل، عرض وطباعة |

الأسماء والبيانات تجريبية. زر "إعادة ضبط البيانات" في القائمة الجانبية يعيدها للوضع الأصلي.
