# معرض أعمال أحمد عبدالرحمن (6 صفحات)

عربي RTL متجاوب بـ HTML/CSS/JS بدون مكتبات. الخط IBM Plex Sans Arabic، والأيقونات SVG، ووضع داكن/فاتح.

| الصفحة | المحتوى |
|---|---|
| index.html | تعريف، مشروع مميّز (منصة SaaS)، مشاريع أخرى، الخدمات، التقنيات، التواصل |
| projects.html | 6 مشاريع مع فلترة |
| project.html?id=N | تفاصيل كل مشروع، التقنيات، رابط المشروع |
| services.html | منصات SaaS، أنظمة ERPNext، مواقع، آلية العمل، أسئلة شائعة |
| about.html | نبذة وأدوات وقيم العمل |
| contact.html | اتصال وواتساب وبريد، نموذج يفتح تطبيق البريد |

بيانات التواصل والروابط في أعلى `script.js` وفي `portfolio.py` عند التوليد. تحديث المشاريع من مصفوفة `PROJECTS` في `script.js`.
