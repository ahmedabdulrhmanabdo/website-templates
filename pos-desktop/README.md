# نظام نقاط البيع (سطح المكتب)


- `index.html`: صفحة العرض بلقطات الشاشة.
- `screens/`: اللقطات (البيع، الدفع، الإيصال، المخزون، التقارير).
- `app/`: مصدر الواجهة (HTML/CSS/JS). تدعم مسح الباركود، الخصم، الضريبة 15% الشاملة، الدفع النقدي/الشبكة/المختلط، تعليق الفاتورة، الإيصال، المخزون، والتقارير.
