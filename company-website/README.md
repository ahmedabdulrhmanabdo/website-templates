# قالب موقع شركة / خدمات

قالب موقع عربي (RTL) متجاوب بـ HTML/CSS/JavaScript بدون أي مكتبات.

**الأقسام:** الرئيسية، الإحصائيات، الخدمات، من نحن، نموذج التواصل.

## التشغيل
افتح `index.html` في المتصفح، أو:
```bash
python3 -m http.server 8000
```

## التخصيص
- الألوان: متغيرات `:root` في `styles.css`.
- النصوص والخدمات: `index.html`.
- نموذج التواصل تجريبي ولا يرسل البيانات؛ اربطه بخدمتك قبل الإنتاج.
