# تطبيقات ويب صغيرة

ثمانية تطبيقات تعمل مباشرة في المتصفح بدون أي تثبيت أو مكتبات. افتح `index.html` في هذا المجلد لتصفّحها كلها.

| التطبيق | الوصف |
|---|---|
| todo-app | قائمة مهام مع تصفية وحفظ تلقائي |
| calculator-app | آلة حاسبة تدعم لوحة المفاتيح |
| pomodoro-app | مؤقّت تركيز وراحة |
| expense-tracker | دخل ومصروف ورصيد |
| notes-app | ملاحظات مع بحث |
| quiz-app | اختبار معلومات عامة (8 أسئلة) |
| unit-converter | تحويل الطول والوزن والحرارة |
| password-generator | مولّد كلمات مرور عشوائية بقياس القوة |

البيانات (المهام والمصروفات والملاحظات) تُحفظ في متصفحك فقط (`localStorage`).
