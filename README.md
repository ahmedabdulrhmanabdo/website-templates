# نماذج تصاميم المواقع

قوالب عربية (RTL) متجاوبة بـ HTML/CSS/JavaScript بدون أي مكتبات. افتح `index.html` داخل أي مجلد أو شغّل `python3 -m http.server`.

| المجلد | الوصف |
|---|---|
| [company-website](company-website) | موقع شركة / خدمات |
| [restaurant-website](restaurant-website) | مطعم: قائمة بتصنيفات وحجز طاولة |
| [portfolio-website](portfolio-website) | معرض أعمال: مشاريع، مهارات، وضع داكن/فاتح |
| [store-website](store-website) | متجر: بحث، تصنيفات، سلة تسوق |
