# قالب مكتب عقاري (5 صفحات)

عربي RTL متجاوب بـ HTML/CSS/JS بدون مكتبات. الخط Readex Pro، والأيقونات SVG.

| الصفحة | المحتوى |
|---|---|
| index.html | بحث سريع، عقارات مميزة، التصنيفات، الخدمات، خطوات الشراء |
| listings.html | 12 عقارًا مع فلاتر (غرض/نوع/مدينة/سعر/غرف) وترتيب، وتقرأ الفلاتر من الرابط |
| property.html?id=N | تفاصيل العقار، المميزات، طلب معاينة، حاسبة تمويل، عقارات مشابهة |
| services.html | 6 خدمات + أسئلة شائعة |
| contact.html | بيانات المكتب ونموذج وخريطة (مكان مخصص) |
